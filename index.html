📌 安全更新指南:
1. 更新前先点"导出备份",保存 JSON 文件
2. 用 Git 分支开发,测试无误再合并主分支
3. 不要修改 localStorage 的 key 名称
4. 新增功能用新函数,不要重写已有逻辑
5. 如需迁移数据,在 migrateData() 中添加迁移规则
6. 如数据丢失,用"导入恢复"还原备份

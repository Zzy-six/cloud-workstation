# ☁️ 云计算学习工作台

> 一个可自定义编辑的云计算学习工作台，记录学习路径、沉淀项目经验、展示求职作品集。

🔗 **线上地址**：[https://zzy-six.github.io/cloud-workstation/](https://zzy-six.github.io/cloud-workstation/)

---

## ✨ 核心功能

### 📊 可编辑内容系统
- 点击右上角 **✏️ 编辑模式** 即可编辑所有内容
- 数据自动保存在浏览器本地（localStorage）
- 支持导出/导入数据备份

### 🔧 功能模块

| 模块 | 功能说明 |
|------|---------|
| **技能树** | 云计算方向技能分类，记录学习进度和笔记 |
| **学习路线图** | 从零基础到就业的阶段性学习路径 |
| **项目实战** | 沉淀动手实践过的项目，作为求职作品集 |
| **学习资源** | 分类收藏优质学习资料 |
| **面试题库** | 云计算高频面试题，点击展开答案 |
| **关于我** | 个人信息、教育背景、技能证书、求职意向 |

### 🎨 界面定制
- 🌙 暗黑模式切换
- 🎨 自定义背景（图片/动图/视频）
- 📐 玻璃质感调节（透明度、模糊、边框）
- 🔤 字体大小/样式/颜色自定义
- 🎯 主题色自定义

### 📱 移动端支持
- 全面流体响应式布局（clamp 自适应）
- 手机端拍照上传头像/证书
- 触控优化的交互体验
- 自动检测新版本并提示更新

### 👤 关于我 - 完整编辑能力

| 区域 | 编辑方式 |
|------|---------|
| 头像 | 点击头像 → 拍照/选择图片/emoji |
| 姓名/职位/简介 | 点击文字直接编辑 |
| 联系方式 | 自定义添加（邮箱/电话/微信/GitHub/链接等） |

## 🚀 本地开发

### 环境要求
- 任何代码编辑器（推荐 VS Code / Trae）
- Python 3.x（用于部署脚本）
- Git（用于版本管理）

### 本地预览
```bash
# 方法1：直接打开
# 用浏览器打开 index.html

# 方法2：启动本地服务器（推荐）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

### 部署上线
```bash
# 修改代码后，更新版本号（3处）：
# 1. script.js → APP_VERSION = "x.x.x"
# 2. version.json → "version": "x.x.x"
# 3. index.html → style.css?v=x.x.x 和 script.js?v=x.x.x

# 执行部署
python deploy_v21.py
```

## 🔄 自动更新机制

网站内置自动更新检测：

1. **页面加载时**：延迟 3 秒检查 `version.json`
2. **定时检查**：每 5 分钟自动检查一次
3. **可见性检测**：切回页面时自动检查
4. **网络恢复**：网络恢复时自动检查

发现新版本后弹出提示，用户点击「立即刷新」即可更新。

## 💾 数据安全

- 所有编辑数据存储在浏览器 **localStorage** 中
- 清除浏览器数据会导致内容丢失
- 建议定期使用「导出备份」功能保存数据
- 更新网站前务必先导出备份

### 备份方法
1. 点击右上角 **🎨 设置** → **数据** 标签
2. 点击 **📥 导出备份**，保存 JSON 文件
3. 需要恢复时点击 **📤 导入恢复**
